# 🌡️ Temperature Converter

A simple and interactive Temperature Converter built using **HTML, CSS, and JavaScript**. This tool allows users to easily convert temperature values between **Celsius and Fahrenheit** with real-time, accurate results. Designed with a clean UI and smooth styling, making it beginner-friendly and easy to use.

## 🚀 Features
- Convert **Celsius ➜ Fahrenheit**
- Convert **Fahrenheit ➜ Celsius**
- Clean and modern UI
- Instant and accurate results
- Fully responsive layout

## 🧠 How It Works
The user enters a temperature value and selects the conversion direction:
- **Celsius to Fahrenheit**:  
  `F = C × 9/5 + 32`
- **Fahrenheit to Celsius**:  
  `C = (F − 32) × 5/9`

JavaScript handles the calculations and updates the result on screen.

## 📥 How to Use

1. Enter a temperature value in the input box  
2. Select a conversion option:
   - Celsius ➝ Fahrenheit
   - Fahrenheit ➝ Celsius  
3. Click the **Convert** button  
4. The result will be shown instantly on the screen
