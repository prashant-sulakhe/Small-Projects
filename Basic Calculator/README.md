# Basic Calculator

A simple and stylish calculator built using **HTML**, **CSS**, and **JavaScript**.
This project performs basic arithmetic operations such as addition, subtraction, multiplication, division, and supports decimal inputs.

## 🔧 Features

* Clean and modern UI
* Supports AC (All Clear) and single-character delete
* Handles basic arithmetic operations (+, −, ×, ÷)
* Error handling for invalid expressions
* Responsive and easy to use

## 🛠️ Technologies Used

* **HTML** – Structure of the calculator
* **CSS** – Styling and layout
* **JavaScript** – Functionality and logic

## 📁 Project Structure

```
│── index.html / calc.html
│── calc.css
│── calc.js
```

## 🚀 How to Use

1. Clone the repository
2. Open the `calc.html` file in any browser
3. Start calculating!
